**Multi-Scale Computational Investigation of Food Antioxidants and Solvation Dynamics**

A three-part computational chemistry project investigating the electronic structure, dynamics, and solvation behavior of five food-derived antioxidants (quercetin, catechin, ascorbic acid, caffeic acid, rutin), using three complementary methodologies:

| Project | Method | Question | Tools |
|---|---|---|---|
| [Project 1](https://github.com/ahadk210-cmyk/Ahad_Khan_Computational_Chemistry) | DFT (Gas-Phase) | What electronic properties drive antioxidant activity? | ORCA, B3LYP/6-31G* |
| [Project 2](https://github.com/ahadk210-cmyk/MD_Project) | Molecular Dynamics | How does an antioxidant behave in an explicit solvent environment? | GROMACS, GROMOS54A7 |
| [Project 3](https://github.com/ahadk210-cmyk/CPCM_Solvation) | Implicit Solvation (DFT) | How does an aqueous environment shift electronic reactivity? | ORCA, CPCM(Water) |

Together, these projects form a coherent multi-scale narrative — from gas-phase quantum mechanics, through explicit molecular dynamics, to solvent-perturbed electronic structure — applied consistently to the same set of antioxidant molecules.
