**Multi-Scale Computational Investigation of Food Antioxidants and Solvation Dynamics**

Three self-directed computational chemistry projects: gas-phase and implicit-solvent electronic structure of five food-derived antioxidants (quercetin, catechin, ascorbic acid, caffeic acid, rutin), and an explicit-solvent molecular dynamics test system on ethanol–water.

| Project | Method | Question | Tools |
|---|---|---|---|
| [Project 1](https://github.com/ahadk210-cmyk/Ahad_Khan_Computational_Chemistry) | DFT (gas phase) | Which electronic descriptors distinguish the five antioxidants, and which is most reactive? | ORCA 6.1.1, B3LYP/6-31G* |
| [Project 2](https://github.com/ahadk210-cmyk/MD_Project) | Molecular dynamics | Can an explicit-solvent MD workflow be set up, equilibrated and run end to end, with stability verified over 500 ps? | GROMACS, GROMOS54A7, SPC water |
| [Project 3](https://github.com/ahadk210-cmyk/CPCM_Solvation) | Implicit solvation (DFT) | Does the gas-phase ordering from Project 1 change in an aqueous dielectric environment? | ORCA 6.1.1, CPCM(water) |

Projects 1 and 3 study the same five molecules in vacuum and in an implicit water model; Project 2 establishes the explicit-solvent MD workflow that the antioxidant systems would extend to. Each repository contains input files, scripts, outputs and a README describing what was done and how.
